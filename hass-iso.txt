EXPERIMENT 1: Install Ubuntu on Oracle VM VirtualBox
--------------------------------------------------------------
AIM:
To install and configure a Linux environment (Ubuntu) using Oracle VM VirtualBox.

BASIC STEPS (GUI based - no commands):
1. Download and install Oracle VM VirtualBox.
2. Download the Ubuntu Desktop ISO image.
3. Open VirtualBox -> click New -> enter name, select ISO, set RAM and CPU.
4. Create a virtual hard disk (25 GB or more recommended).
5. Review System / Display / Storage settings.
6. Start the VM -> follow the Ubuntu installer (language, keyboard, partitioning).
7. Set username and password -> finish installation -> reboot the VM.

TROUBLESHOOTING (short):
- "VT-x/AMD-V disabled" -> enable virtualization in BIOS.
- Lag in guest OS -> give more RAM/CPU and install Guest Additions.

EXPERIMENT 3: Users, Groups, Permissions (chmod, chown, chgrp) and ACLs
--------------------------------------------------------------
AIM:
To create and manage users and groups in Linux and configure file and directory
permissions using chmod, chown, chgrp, and Access Control Lists (ACLs).

BASIC STEPS:
1. Check current user identity.
2. Create a group (developers) and two users (student1, student2).
3. Add both users to the group.
4. Create a shared directory /project, set group owner and permission 770.
5. Create a file as student1, set group developers and permission 660.
6. Edit the file as student2 (group access works).
7. Create an outsider user and show access is denied.
8. Use ACL to give outsider read-only access, test it.
9. Remove the ACL entries.

COMMANDS:
whoami
id

sudo groupadd developers
getent group developers

sudo useradd -m -s /bin/bash student1
sudo useradd -m -s /bin/bash student2
id student1
id student2

sudo usermod -aG developers student1
sudo usermod -aG developers student2
groups student1
groups student2

sudo mkdir /project
ls -ld /project
sudo chown root:developers /project
ls -ld /project
sudo chmod 770 /project
ls -ld /project

sudo -u student1 touch /project/student1_file.txt
sudo -u student1 bash -c 'echo "Created by student1" > /project/student1_file.txt'
cat /project/student1_file.txt
sudo chgrp developers /project/student1_file.txt
sudo chmod 660 /project/student1_file.txt
ls -l /project/student1_file.txt

sudo -u student2 bash -c 'echo "Edited by student2" >> /project/student1_file.txt'
cat /project/student1_file.txt

sudo useradd -m -s /bin/bash outsider
groups outsider
sudo -u outsider ls /project          # Expected: Permission denied

sudo apt install acl -y
sudo setfacl -m u:outsider:rx /project
sudo setfacl -m u:outsider:r /project/student1_file.txt
getfacl /project/student1_file.txt

sudo -u outsider cat /project/student1_file.txt                                # Success
sudo -u outsider bash -c 'echo "Edited by outsider" >> /project/student1_file.txt'   # Permission denied

sudo setfacl -x u:outsider /project/student1_file.txt
sudo setfacl -x u:outsider /project
getfacl /project/student1_file.txt

EXPERIMENT 4: Shell Scripting (File Handling, Backup, Process Monitoring)
--------------------------------------------------------------
AIM:
To write and execute shell scripts in Linux to automate basic system tasks
including file creation, backup management, and process monitoring.

BASIC STEPS:
1. Create a workspace directory.
2. Write and run the file handling script.
3. Write and run the backup script.
4. Write and run the process management script.
5. Verify all scripts and output files.

COMMANDS:
mkdir shellprac
cd shellprac

# --- Script 1: File handling ---
cat > filehandling.sh << 'EOF'
#!/bin/bash
echo "File Handling Started"
mkdir -p datafiles
echo "Hello Linux" > datafiles/file1.txt
echo "Shell Scripting Practical" > datafiles/file2.txt
echo "Files created successfully"
ls -l datafiles
EOF
bash filehandling.sh

# --- Script 2: Backup ---
rm -f backup.sh
echo '#!/bin/bash' > backup.sh
echo 'echo "Backup Started"' >> backup.sh
echo 'mkdir -p backupcopy' >> backup.sh
echo 'cp -r datafiles backupcopy/' >> backup.sh
echo 'echo "Backup completed successfully"' >> backup.sh
echo 'ls -l backupcopy' >> backup.sh
bash backup.sh

# --- Script 3: Process management ---
rm -f process.sh
echo '#!/bin/bash' > process.sh
echo 'echo "Process Management Started"' >> process.sh
echo 'echo "Current User:"' >> process.sh
echo 'whoami' >> process.sh
echo 'echo "Running Processes:"' >> process.sh
echo 'ps | head -n 5' >> process.sh
bash process.sh

# --- Verify ---
ls
ls backupcopy
ls datafiles

EXPERIMENT 9: Build an Open-Source App, Documentation & License Compliance
--------------------------------------------------------------
AIM:
To build and run an open-source application from source code, create
documentation, and perform license identification and compliance checks.

BASIC STEPS:
1. Create practical folder.
2. Check build tools (gcc, make).
3. Create C source file and Makefile.
4. Build with make and run the app.
5. Create README (documentation) and LICENSE files.
6. Identify the license and run compliance check.
7. Create NOTICE file.
8. Clean build files.

COMMANDS:
mkdir ossprac
cd ossprac
pwd

gcc --version
make --version
# If not installed:
sudo apt-get update
sudo apt-get install -y build-essential

printf '#include <stdio.h>\n\nint main() {\n printf("Hello from Open Source App\\n");\n return 0;\n}\n' > helloapp.c
cat helloapp.c

printf 'helloapp: helloapp.c\n\tgcc helloapp.c -o helloapp\n\nclean:\n\trm -f helloapp\n' > Makefile

make
ls -l
./helloapp

echo "# Hello Open Source App" > README.md
echo "This is a simple C application created for OSS practical." >> README.md
echo "Build command: make" >> README.md
echo "Run command: ./helloapp" >> README.md
cat README.md

echo "MIT License" > LICENSE
echo "Permission is hereby granted to use, copy, modify, and distribute this software." >> LICENSE
echo "This software is provided without warranty." >> LICENSE
cat LICENSE

head -n 1 LICENSE
grep -i "MIT" LICENSE

ls README.md LICENSE
grep -i "Permission" LICENSE

echo "This project uses MIT License." > NOTICE.txt
echo "Users must keep the LICENSE file while sharing the project." >> NOTICE.txt
cat NOTICE.txt

make clean
ls

EXPERIMENT 10: Open Source Contribution (GitHub Fork - Branch - PR)
--------------------------------------------------------------
AIM:
To simulate a basic contribution to an open-source project using Git and GitHub
by forking a repository, cloning it locally, creating a branch, making a small
documentation change, committing the change, pushing the branch, and creating a
Pull Request.

BASIC STEPS:
1. Create practical folder and check Git.
2. Configure Git identity.
3. Fork the repository on GitHub (browser step).
4. Clone the fork and check status/remote.
5. Create a contribution branch.
6. Edit README.md (small documentation change).
7. Review, stage and commit the change.
8. Push the branch to GitHub.
9. Create a Pull Request on GitHub (browser step).
10. Verify the contribution.

COMMANDS:
mkdir oss_contribution
cd oss_contribution
pwd

git --version

git config --global user.name "Your Name"
git config --global user.email "your@email.com"
git config --global --list

# Fork on GitHub (browser): open upstream repo -> click Fork

git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

git status
git remote -v

git checkout -b docs/update-readme
git branch

ls
cat README.md

echo "" >> README.md
echo "## Contribution Guide" >> README.md
echo "Contributions are welcome through a Pull Request." >> README.md
cat README.md

git status
git diff

git add README.md
git status
git commit -m "docs: improve contribution guide"
git log -1 --oneline

git push -u origin docs/update-readme

# Create Pull Request on GitHub (browser):
# Compare & pull request -> Base: upstream main, Compare: your docs/update-readme
# Title: Improve README contribution guide

git status
git branch -a

WORKFLOW SUMMARY:
Fork -> Clone -> Branch -> Modify -> Stage -> Commit -> Push -> Pull Request
